# 几何与位移场

## 全合成几何

`src/model.mjs` 的默认配置为宽24m、深20m、高54m，每条表面边分10段。宽/深范围8..60m，高20..100m，分段数2..20。模型由9个基本体组成：灰斗、炉膛、上部塔段、炉顶、左右风道、3个平台。灰斗与炉顶由矩形截面线性过渡；其他部件是分段长方体。所有比例均为软件演示设置，不来自实际设备。

部件描述来自同一配置，分别用于浏览器网格和FreeCAD宏，避免维护两组不一致的尺寸。浏览器采用Y轴向上、米制，底部Y=0且X/Z居中。各部件坐标写入局部顶点数组，模型根缩放固定为1；不靠缩放根节点伪造形变。

这是一组可能相交的封闭基本体，不是布尔融合后的单一实体，不能把整组装配直接当作封闭求解域。

## 热伸长

示意线膨胀系数α=1.1×10⁻⁵/K，温差ΔT范围−100..500K。对于点(x,y,z)，H为几何高度，t=clamp(y/H,0,1)：

```text
dx = 0.1 * α * ΔT * x * t
dy = α * ΔT * y
dz = 0.1 * α * ΔT * z * t
```

底面位移为0；中心轴顶部伸长为αΔTH。径向项仅用于演示，没有求解泊松效应或支吊架约束。

## 壁面鼓胀

仅对炉膛部件施加。将炉膛高度归一化到t∈[0,1]，用sin²(πt)作为高度包络。截面法向用归一化x/z的七次幂近似矩形外法向。示意压力柔度为0.015mm/Pa，压差范围−2000..2000Pa；压力正负分别产生向外/向内位移。

这是手工解析场，没有使用板壳刚度、壁厚或材料；柔度并非已标定的工程参数。

## 烟道下挠

只对左右风道部件施加。沿深度归一化到u∈[0,1]，竖向位移为：

```text
dy = -sag_mm / 1000 * 4*u*(1-u)
```

两端为0，中跨达到给定挠度，范围0..200mm。这里只借用抛物线的形状，不代表梁单元求解。

## 组合、倍率与审计

组合模式线性相加上述位移。每次更新从固定Float32基准重新计算，避免重复应用造成累积；零位移直接回写原始Float32值，包括带符号零，以保证复位字节一致。

解析值先用JavaScript双精度计算，显示坐标为 `baseline + delta * visualScale`，之后写入Float32顶点缓冲区。显示倍率范围1..40，仅改变显示坐标；导出模型强制使用1倍解析位移。画面实测值可能存在Float32舍入差异。

未放大解析位移与画面缓冲区位移分别统计。探针是每个相关部件本次解析位移最大的顶点记录；全零时选择顶部记录。索引可能随模式或网格密度变化，不是固定物理测点。FNV指纹只用于快速比较，不是唯一性或安全保证；导出文件另用SHA-256校验。
